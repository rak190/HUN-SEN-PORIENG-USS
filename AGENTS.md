# Comprehensive & Confident Execution
When pair programming or executing tasks:
1. **Maximize Throughput**: Do not take overly cautious, tiny incremental steps. Write comprehensive, multi-file code changes in a single pass whenever possible. 
2. **Zero-Bug Priority**: Before writing code, rapidly scan all related components to deeply understand the architecture. Anticipate edge cases, state management issues, and React lifecycle bugs before they happen.
3. **Holistic Implementation**: When implementing a feature, complete the UI, the state management, the API integration, and the error handling all at once. Do not leave "TODOs" or partial implementations unless explicitly requested.
